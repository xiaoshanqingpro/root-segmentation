## 0. 先说两个新发现（交接文档里没有的）

### 发现一：代码参数与文档记录不一致 ⚠️

`code\rootseg_common.py` 当前实际是：

| 参数 | 代码现状 | 交接文档 §5 / 模型优化报告 §3 记录 |
|---|---|---|
| `SHRINK_PX` | **0**（不收边） | **1** |
| `HALO_GROW` | **6** | **0**（实测无效已关闭） |

也就是说：**送扫的那 6 张机器图用的参数，和现在代码里的参数不是同一套**。
不清楚是哪次改动留下的。在动任何优化之前，必须先对齐并冻结配置，
否则后面所有实验都无法复现、无法归因。

### 发现二：分析区混杂因素已实锤，比预想严重

重新解析 `测试\测试数据.TXT`（GBK，制表符分隔）：

| 样本 | 人工修图分析区 (cm²) | 机器修图分析区 (cm²) |
|---|---|---|
| 28-CL-003 | **184.4** | **70.5** |
| 126-003 | 530.7 | 451.3 |
| 134-003 | 489.5 | 409.6 |
| 66-003 | 460.5 | 454.2 |
| G218-001 | 490.6 | 499.3 |

机器图是纯白背景，WinRHIZO 自动圈定的分析区明显变化（28-CL-003 差 2.6 倍）。
**这意味着 §1.1 那张端到端对比表里，每一行差异都混入了"分析区不同"的噪声**，
偏小的结论方向大概率成立，但具体数值不可全信。这是当前评估体系最大的洞。

## 2. 优化路线（四层，按顺序做，每层有明确的停/走判据）

### 第 0 层：修评估口径（0.5 天，不做后面全白做）

1. **固定分析区**：在人工修图和机器修图上叠加**同一个固定矩形分析框**
   （或在 WinRHIZO 里手动指定同一 Region），重扫 12 张图。
   → 得到一份"干净基线"，之后所有实验都跟它比。
2. **配置冻结**：把 `rootseg_common.py` 顶部参数抽成 `config\params_v1.yaml`，
   代码从 yaml 读参；每批产物 manifest 记录参数版本号。
   对齐发现一的不一致：确认送扫批次到底用的哪套，代码改回一致。
3. **顺手验证**：用 `SHRINK_PX=0`（不收边）重出 6 张送扫。
   若偏小消失、偏大回归在 ±5% 内，说明偏小就是收边过头的直接后果。

**走/停判据**：拿到固定分析区下的干净基线表。

### 第 1 层：规则管线最后一步——亚像素宽度标定（1~2 天）

收边只能 0 或 1px，没有中间档，这是 P2 的直接原因。两个等价思路，选一：

- **距离变换收边**：保留像素满足 `dist ≥ 局部半宽 × r`，`r` 连续可调（如 0.05~0.15），
  相当于"按宽度比例收边"，打破整数像素台阶；
- **软掩膜阈值标定**：上采样后不取 0.5 硬阈值，保留 [0,1] 连续掩膜，
  在 6 张真值上扫阈值 t（0.3~0.7），选让四项指标偏差中位最接近 0 的 t。

**走/停判据**：若 G218-001 根总长仍差于 −15%，**规则路线到此为止，不再投入**，
直接进第 2 层（这也是交接文档 §1.3 的结论，本方案同意）。

### 第 2 层：U-Net 语义分割（主线，1~2 周）

交接文档 §9 已给出方向，这里补具体设计：

- **数据**：6 张人工真值，512×512 patch，**按整图划分**；6 张做留一交叉验证（LOO）。
- **模型**：`segmentation-models-pytorch` 的 `Unet(encoder_name="resnet34")`，ImageNet 预训练。
- **输入增强通道**（小数据关键 trick）：RGB 之外，把规则管线的中间特征
  （局部暗度 depth、Frangi 管状响应、饱和度）拼成额外输入通道 —— 相当于把手工先验喂给网络。
- **输出软掩膜 + 距离变换辅助头**：推理得到概率图，二值化阈值 t 连续可调，
  直接获得"直径偏差旋钮"（解决 P2 的根治版）。
- **损失**：Dice + CE，边界像素加权；batch 4，8G 显存可行。
- **增强**：翻转 / 90° 旋转 / ±20% 亮度抖动 / 弹性形变；推理加 TTA。
- **可选加速**：先用规则管线在 286 张白底图上的掩膜做**伪标签预训练**，
  再用 6 张真值微调 —— 小样本场景的标准做法。

**验收判据**：LOO 下 G218-001 和 7-003 两头都压进 ±10%；
然后出图送 WinRHIZO 端到端复核（用第 0 层的固定分析区口径）。

### 第 3 层：扩真值 + 全量（视第 2 层结果启动）

- 再精修 15~20 张（**重点补"极淡细根"类型**），留 5 张独立测试集不参与训练。
- 全量推理：滑窗重叠 + 软掩膜平均，随机抽 5% 人工质检。

## 3. 工程配套（贯穿所有层）

1. 参数配置化（yaml）+ 产物 manifest 记录参数/代码版本 —— 杜绝发现一重演。
2. 指标报告固定模板：逐张数值 + 中位数 + bootstrap 置信区间，不报"效果不错"。
3. 像素级指标（IoU/召回/精确）只是代理，**WinRHIZO 端到端四项指标才是最终判据**。
4. 每层先出结果给你确认，确认后再进下一层。
