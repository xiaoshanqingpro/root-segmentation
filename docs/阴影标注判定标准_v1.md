## 0. 前置：标注在哪张图上做

标注对象是 `根系分割项目/processed/600dpi/` 里的图，**不是原图**。它已经过：

- 按图裁掉边缘伪影带（左边缘粉色刻度尺、托盘边、纸边暗带）
- 统一重采样为 **600 dpi**（原 0814 批次的 10 张是 720 dpi，已缩放 0.8333）

**换算统一为 600 dpi：1 px = 25.4/600 = 0.042333 mm，1 mm = 23.62 px。**

mask 命名：`<原文件名>_mask.png`，尺寸与 `processed/600dpi/` 中对应图**完全一致**。

### 0.1 与人工操作口径的对齐（本版新增，关键）

用户人工倒背景时使用**油漆桶工具、容差 20**（2026-09-22 反馈）。自动处理一律对齐该口径：

- 背景去除 = **边界种子洪水填充，容差 20**（`code/14_whiten.py`，与油漆桶算法等价）
- 只有落在容差 20 之外的连通前景才可能被判为根 —— 与人工结果口径一致

> 已知副作用（接受）：比背景暗不足 20 灰阶的**极淡细根会被填掉**。
> 这是容差 20 本身的取舍，人工用油漆桶时同样存在。

## 1. 三类定义（维持三类）

| 值 | 类名 | 定义 |
|---|---|---|
| 0 | 背景 | 白纸/托盘本体，即"局部正常照明下的纸面" |
| 1 | 根 | 呈现**连续管状/线性结构**、有可追踪走向与轮廓的根系像素 |
| 2 | 阴影 | 比局部背景明显暗、但**没有线性结构**的区域 |

### 1.1 判为「根」的（含边界情形）

1. 主根、侧根、根尖，包括细到 1–2 px 的末级细根。
2. **根自身的柔和暗边（离焦半影）计入根类。** ✅ 用户已确认
   - 用户原话："贴根半影部分计入根系……贴根半影可以适当修剪"
   - 实现口径：以根芯为基础**适度外扩（上限 6 px ≈ 0.25 mm）**，
     与外扩范围内仍属前景且偏暗的像素合并；**不做无限膨胀**
   - 实测依据：阴影像素里 23.4% 落在离根 ≤6 px 处，属根的厚度/离焦效应，不是独立阴影
3. 两根交叉/重叠处更黑的区域：它就是个根像素。
4. 根上颜色偏深、偏褐的段落。

### 1.2 判为「阴影」的

1. **纸面褶皱、压痕**造成的低频明暗不均（无边界、大面积）。
2. **照明不均**：扫描光源条状/渐变造成的不均匀。
3. **水渍 / 湿痕**：灰蓝色、边缘柔和、常呈环状的成块区域（`F120-001` 左下角是典型）。
4. **托盘边 / 纸边压痕**：裁剪后仍残留在画幅内的暗带。
5. **暗但没有线性结构的区域一律算阴影**——本标准的首要判据。

### 1.3 判为「背景」的

1. 孤立小暗点：灰尘、纸屑、纤维、毛发（无管状走向、无分叉）
   → **判背景** ✅ 用户确认与测量口径一致。
   实现口径：连通块面积 < 40 px（≈0.07 mm²）直接判背景。
2. 比背景暗不足容差 20 的极淡区域（会被洪水填充直接吸收，见 §0.1）。
3. 若裁剪后仍有粉色刻度尺残留 → 判阴影（不判根），并**单独记入疑难清单**。

## 2. 边界规则（按优先级从高到低）

1. **看结构，不看深浅**：有管状走向 → 根；只有明暗变化 → 阴影。
2. **过渡带**：根与背景之间的渐变像素，以"能否看出根的管状走向"为准；能 → 根，不能 → 背景。
3. **保守兜底**：实在判不出来 → 判**背景**。✅ 用户已接受
   好处：不会虚增根长；代价：可能漏掉少量极细根。
4. **逐像素、不画圈**：mask 是像素级标签，不要用粗笔刷涂抹，边缘按实际轮廓走。

## 3. 疑难类型清单

**像素级示例图：`outputs/阶段二/standard_examples/rule_A..D.png`**
（1:1 像素放大 3 倍；绿=建议判根 红=建议判阴影；图上标了实测宽度/饱和度/距离）

| 规则 | 示例图 | 来源图 | 实测证据 |
|---|---|---|---|
| A 贴根半影 → 判根 | `rule_A.png` | `0808\F120-001` | 暗边到根缘平均 4.1 px = 0.746 mm |
| B 暗但无线性结构 → 判阴影 | `rule_B.png` | `0808\F120-003` | 暗区离最近根很远、无管状走向 |
| C 水渍/湿痕 → 判阴影 | `rule_C.png` | `0807\G7-003` | 区内平均饱和度 0.067（灰蓝调，与褐色根可分） |
| D 极细根 vs 孤立碎屑 | `rule_D.png` | `0814\G218-002` | 细根粗 44 px = 1.848 mm，长宽比 9.1 |

| 类型 | 说明 | 倾向 |
|---|---|---|
| 贴根水渍 | 水渍紧贴根缘，与根的半影连成一片 | 水渍区宽于半影（>10 px）→ 判阴影；否则判根 |
| 根 × 褶皱交叉 | 褶皱暗带正好压在根上 | 根的部分判根，向两侧延伸的暗带判阴影 |
| 深色根团 | 多根缠绕成一团，内部全黑 | 整团判根（不拆分） |
| 极细根 | 直径 1–2 px、断断续续 | 能连成走向的判根；孤立碎点判背景 |
| 根尖渐隐 | 根尖逐渐淡入背景 | 以肉眼可辨的最后一段判根 |

> **v0 示例图的已知缺陷（用户指出，v1 已修正）**：
> v0 的 A / B / D 三张图绿区**没有完全覆盖极细根**，只有 C 覆盖完整。
> 原因是那三张当时用的是纯经典方法的"根芯"，未并入洪水填充前景与 SAM。
> **v1 起示例图改用 `14_whiten.py` 的前景口径重新生成**，细根覆盖率已修正。

## 4. 阶段一的实测依据（供核对标准是否合理）

| 事实 | 数值 | 对本标准的影响 |
|---|---|---|
| 背景亮度 | 基本纯白（V 饱和 1.0） | 问题不在对比度，在背景不均 |
| 阴影嫌疑占比 | 中位 5.4%，p95 14.6%，最大 21.0% | 阴影普遍存在，必须单列一类 |
| 阴影像素到最近根距离 | 中位 18 px；≤6 px 占 23.4%，>25 px 占 42.6% | 阴影主体独立 → 支持三类；贴根部分用 §1.1(2) 兜住 |
| 经典方法最好成绩（照度校正+Otsu） | 阴影误判为根 16.6%，根召回 90.3% | 经典方法不够 → 深度方案有必要 |
| 边缘伪影带 | 左 16 张（4–13 mm），上下各几张 | 已用裁边处理，标准里只需处理残留 |
