## 0. 前置：标注在哪张图上做

标注对象是 `根系分割项目/processed/600dpi/` 里的图（原图只读）。已做过：

- 按图裁掉边缘伪影带（粉色刻度尺、托盘边、纸边暗带）
- 统一重采样为 **600 dpi**（原 0814 批次的 10 张 720 dpi 已缩放 0.8333）

**换算统一：1 px = 25.4/600 = 0.042333 mm，1 mm = 23.62 px。**

mask 命名 `<原文件名>_mask.png`，尺寸与对应输入图**逐像素一致**。

### 0.1 与人工操作口径的对齐

用户人工倒背景使用**油漆桶工具、容差 20**。自动处理一律对齐：

- 去背景 = **边界种子洪水填充，容差 20**（`code/14_whiten.py`），并补内部亮点种子
  （第二数据集四边有扫描仪黑边，只从边界播种会把整张图判成前景）
- 只有落在容差 20 之外的连通前景才可能被判为根

> 副作用（已知并接受）：比背景暗不足 20 灰阶的**极淡细根会被填掉**。人工用油漆桶时同样如此。

## 1. 三类定义（维持三类）

| 值 | 类名 | 定义 |
|---|---|---|
| 0 | 背景 | 白纸/托盘本体，即"局部正常照明下的纸面" |
| 1 | 根 | 呈现**连续管状结构**、且**不闭合**的根系像素 |
| 2 | 阴影 | 比局部背景明显暗、但没有线性结构的区域 |

### 1.1 判为「根」的

1. 主根、侧根、根尖，包括细到 1–2 px 的末级细根。
2. **根自身的柔和暗边（离焦半影）计入根类** ✅
   - 用户原话："贴根半影部分计入根系……贴根半影可以适当修剪"
   - 实现：以根芯为基础**适度外扩（上限 6 px ≈ 0.25 mm）**，
     与外扩内仍属前景且偏暗的像素合并；**不做无限膨胀**
3. 两根交叉/重叠处更黑的区域：它就是个根像素。
4. 根上颜色偏深、偏褐的段落。

### 1.2 判为「阴影」的

1. 纸面褶皱、压痕造成的低频明暗不均（无边界、大面积）。
2. 照明不均：扫描光源条状/渐变造成的不均匀。
3. **水渍 / 湿痕本体**：灰蓝色、边缘柔和、常呈环状的成块区域。
4. 托盘边 / 纸边压痕。
5. **暗但没有线性结构的区域一律算阴影**——首要判据。

### 1.3 判为「背景」的

1. 孤立小暗点：灰尘、纸屑、纤维、毛发（无管状走向、无分叉）→ **判背景** ✅
   实现：连通块面积 < 40 px（≈0.07 mm²）直接判背景。
2. **水渍反光形成的细小闭合线条** → **判背景，绝不判根** 🆕 **v2 新增**
   - 用户原话："第二个数据集修改背景之后出现的此类细小闭合线条也是水渍带来的反射"
   - 视觉特征：极细（半宽 ≤ 2 px）、平滑、**闭合或近似闭合**、常呈弧线/环，
     多浮在根旁边，有时搭在根上；颜色深浅不定（可能和根一样深）
   - **为什么必须单列**：它**有线性走向**，会触发 Frangi 管状响应，
     按 §1.1 的"有管状走向就判根"会被**系统性误判为根**，直接虚增根长
   - **判据（本质区别）**：**根是树状结构，不会闭合；反光线是闭合的**
   - 实现：细壁围出的洞在**形态学开运算**后会消失，据此定位反光细线
     （`code/14_whiten.py` 的 `REMOVE_REFLECTION`，`code/17_reflection_rings.py` 为检测脚本）
3. 比背景暗不足容差 20 的极淡区域（会被洪水填充吸收）。
4. 裁剪后仍有粉色刻度尺残留 → 判阴影（不判根），记入疑难清单。

## 2. 边界规则（按优先级从高到低）

1. **先看闭不闭合，再看有没有管状走向** 🆕 v2 调整优先级
   - 闭合/成环 → **反光**，判背景（无论多细多深）
   - 有走向且不闭合 → 根
   - 只有明暗变化 → 阴影
2. 过渡带：以"能否看出根的管状走向"为准；能 → 根，不能 → 背景。
3. 保守兜底：判不出来 → 判**背景** ✅（已接受）。不会虚增根长；代价是可能漏掉少量极细根。
4. 逐像素、不画圈：边缘按实际轮廓走。

## 3. 疑难类型清单

**像素级示例图：`outputs/阶段二/standard_examples_v1/rule_A..D.png`**
（1:1 放大 3 倍；绿=根 红=阴影；已按洪水填充前景口径重做，细根完整覆盖）

| 规则 | 示例图 | 来源图 | 实测证据 |
|---|---|---|---|
| A 贴根半影 → 判根 | `rule_A.png` | 0807\G7-003 | 暗边到根缘平均 3.8 px = 0.809 mm |
| B 暗但无线性结构 → 判阴影 | `rule_B.png` | 0814\G218-002 | 暗区离最近根很远 |
| C 水渍/湿痕 → 判阴影 | `rule_C.png` | 0807\G66-003 | 区内平均饱和度低（灰蓝调） |
| D 极细根 vs 孤立碎屑 | `rule_D.png` | 0807\G66-001 | 细根粗 44 px = 1.872 mm |

| 类型 | 说明 | 倾向 |
|---|---|---|
| **水渍反光细线** 🆕 | 极细、闭合/成环、平滑，浮在根旁或搭在根上 | **判背景**（不是根，也不是阴影） |
| 贴根水渍 | 水渍紧贴根缘，与根的半影连成一片 | 水渍区宽于半影（>10 px）→ 判阴影；否则判根 |
| 根 × 褶皱交叉 | 褶皱暗带压在根上 | 根的部分判根，两侧暗带判阴影 |
| 深色根团 | 多根缠绕成一团，内部全黑 | 整团判根（不拆分） |
| 极细根 | 直径 1–2 px、断断续续 | **不闭合**且能连成走向的判根；孤立碎点判背景 |
| 根尖渐隐 | 根尖逐渐淡入背景 | 以肉眼可辨的最后一段判根 |

## 4. 阶段一的实测依据

| 事实 | 数值 | 对本标准的影响 |
|---|---|---|
| 背景亮度 | 基本纯白（V 饱和 1.0） | 问题不在对比度，在背景不均 |
| 阴影嫌疑占比 | 中位 5.4%，p95 14.6%，最大 21.0% | 阴影普遍存在，必须单列一类 |
| 阴影像素到最近根距离 | 中位 18 px；≤6 px 占 23.4%，>25 px 占 42.6% | 阴影主体独立 → 支持三类 |
| 经典方法最好成绩 | 阴影误判为根 16.6%，根召回 90.3% | 经典方法不够 → 深度方案有必要 |
| 边缘伪影带 | 左 16 张（4–13 mm） | 已用裁边处理 |
| **反光细线（v2 新增实测）** | 数据集1：17/106 张、共 22 处；数据集2 的 9.15：7/30 张、8 处 | 比例不高但**会稳定误判成根**，必须处理 |
