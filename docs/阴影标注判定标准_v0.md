## 1. 三类定义

| 值 | 类名 | 定义 |
|---|---|---|
| 0 | 背景 | 白纸/托盘本体，即"局部正常照明下的纸面" |
| 1 | 根 | 呈现**连续管状/线性结构**、有可追踪走向与轮廓的根系像素 |
| 2 | 阴影 | 比局部背景明显暗、但**没有线性结构**的区域 |

### 1.1 判为「根」的（含边界情形）

1. 主根、侧根、根尖，包括细到 1–2 px 的末级细根。
2. **根自身的柔和暗边（离焦半影）**：沿根走向、紧贴根缘、宽度通常 ≤ 6 px（≈0.25 mm）的渐变暗带。
   → 这一条是阶段一实测得来的：阴影像素里 23.4% 落在离根 ≤6 px 的位置，属于根的厚度/离焦效应，**不是独立阴影**。
   → 计入根类，是为了**不让根径被削细、根长被截短**。
3. 两根交叉/重叠处更黑的区域：它就是个根像素。
4. 根上颜色偏深、偏褐的段落。

### 1.2 判为「阴影」的

1. **纸面褶皱、压痕**造成的低频明暗不均（无边界、大面积）。
2. **照明不均**：扫描光源条状/渐变造成的不均匀。
3. **水渍 / 湿痕**：灰蓝色、边缘柔和、常呈环状的成块区域（`F120-001` 左下角是典型）。
4. **托盘边 / 纸边压痕**：裁剪后仍残留在画幅内的暗带。
5. **暗但没有线性结构的区域一律算阴影**——这是本标准的首要判据。

### 1.3 明确**不算根**、也不算阴影的（直接判背景）

1. 孤立小暗点：灰尘、纸屑、纤维、毛发（无管状走向、无分叉）。
2. 若裁剪后仍有粉色刻度尺残留 → 判阴影（不判根），并**单独记入疑难清单**，我回头加宽裁剪量。

## 2. 边界规则（按优先级从高到低执行）

1. **看结构，不看深浅**：有管状走向 → 根；只有明暗变化 → 阴影。
2. **过渡带**：根与背景之间的渐变像素，以"能否看出根的管状走向"为准；能 → 根，不能 → 背景。
3. **保守兜底**：实在判不出来 → 判**背景**，并在疑难清单登记文件名 + 大致位置（不要凭猜判成根，
   否则直接污染根长/根面积）。
4. **逐像素、不画圈**：mask 是像素级标签，不要用粗笔刷涂抹，边缘按实际轮廓走。

## 3. 疑难类型清单（遇到就登记，我统一复核）

**像素级示例图见 `outputs/阶段二/standard_examples/rule_A..D.png`**
（1:1 像素放大 3 倍，绿=建议判根、红=建议判阴影，图上标了实测宽度/饱和度/距离）

| 规则 | 示例图 | 来源图 | 实测证据 |
|---|---|---|---|
| A 贴根半影 | `rule_A.png` | `0808\F120-001` | 暗边到根缘平均 4.1 px = 0.746 mm |
| B 暗但无线性结构 | `rule_B.png` | `0808\F120-003` | 暗区离最近根很远、无管状走向 |
| C 水渍/湿痕 | `rule_C.png` | `0807\G7-003` | 区内平均饱和度 0.067（灰蓝调，与褐色根可分） |
| D 极细根 vs 碎屑 | `rule_D.png` | `0814\G218-002` | 细根粗 44 px = 1.848 mm，长宽比 9.1 |

| 类型 | 说明 | 倾向 |
|---|---|---|
| 贴根水渍 | 水渍紧贴根缘，且边界与根的半影连成一片 | 若水渍区宽于根的半影（>10 px）→ 判阴影；否则判根 |
| 根 × 褶皱交叉 | 褶皱暗带正好压在根上 | 根的部分判根，向两侧延伸的暗带判阴影 |
| 深色根团 | 多根缠绕成一团，内部全黑 | 整团判根（不拆分） |
| 极细根 | 直径 1–2 px、断断续续 | 能连成走向的判根；孤立碎点判背景 |
| 根尖渐隐 | 根尖逐渐淡入背景 | 以肉眼可辨的最后一段判根 |

> ⚠️ 看示例图时请注意一个**重要事实**：上面红区（我的"阴影"建议）面积普遍偏大，且大量紧贴根缘。
> 原因是**经典流水线的根掩膜只抓到了"根芯"，比真实根轮廓细**，被它漏掉的根缘就被划进了红区。
> 这恰恰说明"贴根部分到底算根还是算阴影"这条口径必须由你定死——
> 它直接决定根径是量粗还是量细。这也是深度模型 + 人工标注要解决的核心问题。

## 4. 阶段一的实测依据（供你核对标准是否合理）

| 事实 | 数值 | 对本标准的影响 |
|---|---|---|
| 背景亮度 | 基本纯白（V 饱和 1.0） | 问题不在对比度，在背景不均 |
| 阴影嫌疑占比 | 中位 5.4%，p95 14.6%，最大 21.0% | 阴影普遍存在，必须单列一类 |
| 阴影像素到最近根距离 | 中位 18 px；≤6 px 占 23.4%，>25 px 占 42.6% | 阴影主体独立 → 支持三类；贴根部分用 1.1(2) 兜住 |
| 经典方法最好成绩（照度校正+Otsu） | 阴影误判为根 16.6%，根召回 90.3% | 经典方法不够 → 深度方案有必要 |
| 边缘伪影带 | 左 16 张（4–13 mm），上下各几张 | 已用裁边处理，标准里只需处理残留 |

## 5. 待你确认/修订的点

1. 1.1(2) 把"贴根半影计入根"——**这条会直接影响根径测量**，请确认口径。
2. 1.3(1) 灰尘/纤维判背景——若你的测量口径要求剔除所有非根暗物，这条一致；否则要改。
