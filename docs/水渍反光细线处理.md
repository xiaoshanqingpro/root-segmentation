# 水渍反光细线：处理说明与校准请求

依据用户 2026-09-22 反馈：**"第二个数据集修改背景之后出现的此类细小闭合线条也是水渍带来的反射"**

---

## 1. 为什么这条必须单独立规则

这类反光线有一个**致命特征**：它**有线性走向**。

而 v1 标准的首要判据是"有管状走向 → 根"（§1.1），Frangi 管状增强会**稳定地在它上面亮起来**。
所以按 v1 标准，反光线会被**系统性误判成根**，直接虚增根长和根面积。

**本质区别**：

| | 根 | 水渍反光细线 |
|---|---|---|
| 拓扑 | **树状**（有分叉、有端点、**不闭合**） | **闭合/成环**（无端点） |
| 粗细 | 再细也有实心厚度 | 极细、平滑 |
| 成因 | 植物组织 | 水面/玻璃面形成的"影子" |

→ **判据就落在"闭不闭合"上**，而不是粗细或深浅。这条已写入标准 v2 §1.3(2) 与 §2.1。

## 2. 自动检测算法（以及踩的坑）

### 第一版（错）——按连通块找"细 + 闭合"

反光线一旦与根相连就并成一个大块，整块的半宽由**根**决定 → 判不出来。
实测第一数据集与第二数据集**双双报 0**，完全失效。

### 第二版（也错）——取洞外沿 1px 的壳，看壳的 dt

那层壳天生就只有 1px 厚，距离变换值**恒等于 1.40**，判据退化成"所有洞都是反光"。
实测第二数据集 9.15 **30/30 全部命中**，是彻底的假阳性。

### 第三版（当前）——用**开运算**测"壁厚"

原理：
- **细壁**围出的洞，在形态学开运算（结构元半径 2）之后会连同细壁一起被抹掉，
  洞与外部连通 → 该洞在开运算结果里**不再是洞**
- **厚壁**围出的洞（比如根与根之间的缝隙）则纹丝不动

于是：`反光洞 = 在原掩膜里是洞，但在开运算结果里不再是洞`，
再取紧邻这些洞的掩膜像素作为反光线剔除。

代码：`code/14_whiten.py` 的 `REMOVE_REFLECTION` 段；独立检测脚本 `code/17_reflection_rings.py`。

## 4. 校准样本与结论（2026-09-22 补充）

### 你给的线索

你说样本来自 **9.9**，并补充：**"那是我修了一半的图片，先使用油漆桶改了背景之后会出现这样的水泡"**。

这解释了机制：**水泡轮廓是原图里就有的**，只是一直混在背景纹理里看不出来；
**油漆桶把纸面倒成纯白之后**，这些比背景暗 20 灰阶以上的水泡轮廓线就凸显出来了。

### 找到的正样本

`采样数据\图片\多样性林\9.9改\44-001.tif` —— 右侧有一条**大而细的闭合水泡轮廓线**，正是你说的那种。
（顺带发现 `9.9改` 里今天又多了 `44-001.tif`，看来你正在处理这批。）

### 拓扑判据（闭不闭合）在真实数据上**不可靠**

三次尝试全部失败，记录备查：

| 尝试 | 做法 | 失败原因 |
|---|---|---|
| 1 | 按连通块找"细+闭合" | 反光线与根相连就并成一块，半宽由根决定 → 两个数据集全报 0 |
| 2 | 取洞外沿 1px 壳看厚度 | 壳天生 1px，dt 恒为 1.40 → 退化成"所有洞都是反光"，30/30 假阳性 |
| 3 | 开运算测壁厚 | 在 1400~2600 特征尺度上，细线被压成亚像素并**碎成 2296 个连通块**，洞根本形不成 |

**根因**：反光线太细，在工作尺度上会断裂；而拓扑判据依赖"完整闭合"，对断裂零容忍。

### 改用更朴素的判据：**细结构必须更黑才算根**

观察：在 `44-001` 上，水泡线是**淡灰**的，而根是**近黑**的。
于是规则改为：

```
粗结构（开运算半径 3 保留下来的）        -> 判根，不看深浅
细结构（不属于粗结构、且远离粗结构）     -> 必须"够黑"（深度 > 45）才判根
```

物理依据：**根再细也是实心组织，颜色深**；**水泡轮廓是水膜的边缘反光，颜色浅**。

**在 `44-001` 上的实测**：

| 指标 | 数值 |
|---|---|
| 原判根 | 185438 px |
| 应用规则后 | 148751 px |
| 剔除 | 36687 px（**19.8%**） |
| 其中细结构 | 49215 px |
| 保留下来的"黑色的细结构"（真根尖） | 26939 px |

局部放大对比（`outputs\反光核对\44-001_zoom.png`，三格：原判根 / 应用规则后 / 原图）：
**那条淡色水泡闭合线被剔除了（红色），而所有粗根和黑色的细根尖都完整保留。**

### ❌ 用户复核结论：这条规则**作废**（2026-09-22）

用户看过 `44-001_zoom.png` 后的反馈：

> "有一些真根被误删了"、"中间那个红被剔除的好像全部剔到根中间了"

**结论：`22_thin_contrast_rule.py` 的"细结构高对比"规则不采用，已在管线中保持关闭。**
失败原因分析：该规则按"离粗结构 >9px"来划细结构，这个几何条件并不能等同于"水泡线"——
**脱离粗结构的那一段真根（尤其根尖、远离主根的侧根）同样落在里面**，
而它们只要比阈值淡一点就会被误删。误删真根不可接受（根长直接损失），故放弃。

**当前管线对水泡线的处理策略：不自动删，只按 v2 标准在标注环节人工判定。**
`14_whiten.py` 中的闭合环过滤（`REMOVE_REFLECTION`）保持保守阈值 2.0，
实测在第一数据集不删任何像素；对第二数据集也先不启用，等你确认处理方案。

> 保留的可用价值：`code/17_reflection_rings.py` 可作为**提示工具**输出候选，
> 但不再作为自动删除依据。
